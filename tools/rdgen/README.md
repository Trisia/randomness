# 随机数生成工具 rdgen 使用说明


## 概述

该工具用于生成符合《GM/T 0005-2021 随机性检测规范》 5 随机发生器检测概述 的数据集合。

随机数采集自 `"crypto/rand` 包提供的随机源，在不同平台上有不同的实现方式。

## 编译

切换到`tools/rddetector`目录内运行，编译命令即可

```
go build .
```

## 工具文档

工具用法如下，默认情况按照 《GM/T 0005-2021》设定的样本数量 1000 每组随机数长度不小于 10^6比特运行，
运行结果将会保存在文件中。

```
randomness 随机数生成工具 rdgen 使用说明

rdgen [-s 生成文件数] [-n 每个文件内bit数] [-o 生成位置] [-seed 种子] [-q]

        示例: rdgen -s 1000 -n 1000000 -o ./data

-n int
    number 每个样本长度(bit)，必须是 8 的倍数 (默认值 1000000)
-o string
    output 生成随机数文件存放目录 (默认值 "target/data")
-s int
    Sample 样本数量 (默认值 1000)
-seed uint
    确定性种子；非 0 时使用内置确定性发生器，同一组 -seed/-s/-n 生成完全相同的文件内容
    (默认值 0，表示使用 crypto/rand)
-q  安静模式，只输出汇总信息
```

## 可复现的测试数据

默认使用 `crypto/rand`，每次运行结果不同。指定 `-seed` 后改用库内的
确定性发生器 `randomness.NewDetRand`（实现见根目录 `detrand.go`，
xoshiro256\*\*，算法固定、与 Go 版本/平台/架构无关），
第 i 个文件由 `seed+i` 生成，因此：

```
rdgen -s 3 -n 20000 -o ./data -seed 20240920
```

在任意机器、任意 Go 版本上都产出完全相同的三个文件。这对把检测结果
固化为回归基线很有用：数据可复现，报告才可比对。

注意：该发生器是**确定性伪随机**，仅用于生成可复现的测试数据，
不可用于任何需要密码学安全随机性的场景。
